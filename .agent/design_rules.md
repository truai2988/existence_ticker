# デザインシステム・ガイドライン (タイポグラフィ)

このプロジェクトでは、視覚的な一貫性と哲学的な表現を維持するために、以下のフォントルールを厳守してください。

## 1. フォント・ファミリー (Font Families)

役割に応じて Serif と Sans を使い分けてください。

| 役割                           | フォント             | Tailwind クラス |
| :----------------------------- | :------------------- | :-------------- |
| **哲学・物語・重要見出し**     | Noto Serif JP        | `font-serif`    |
| **機能的UI・標準本文・ボタン** | Inter / Noto Sans JP | `font-sans`     |

### 使い分けの詳細:

- **Serif (`font-serif`)**: ストーリーの内容、詩的なメッセージ、セクションのメインタイトル（「源気」「お裾分けの目安」など）。
- **Sans (`font-sans`)**: 入力フォーム、ボタン、補助的なラベル、ステータス表示、技術的な情報。

---

## 2. フォント・サイズ (3-size Rule)

原則として以下の3つのサイズのみを使用します。中間サイズ（`text-sm`, `text-lg`, `text-xl`, `text-2xl`）は使用せず、最も近いものに割り当ててください。

| 呼称        | Tailwind クラス    | 推奨される用途                                   |
| :---------- | :----------------- | :----------------------------------------------- |
| **Large**   | `text-3xl` (30px)  | 見出し、ヒーローテキスト、主要な数値（Lm量など） |
| **Regular** | `text-base` (16px) | 本文、説明文、標準的なUIテキスト                 |
| **Small**   | `text-xs` (12px)   | キャプション、補足情報、小さなラベル             |

### 例外ルール:

- **Hero Display**: ランディングページのトップに表示される巨大な数字など、デザイン上不可欠な場合は `text-6xl` 〜 `text-9xl` を使用しても構いません。
- **モバイル調整**: デバイスサイズに応じて `md:text-3xl` のようにレスポンシブクラスを付与することを推奨します。

---

## 3. エージェントへの指示 (For AI Agents)

新しい機能を実装したり、コードを修正したりする際は、必ずこのファイルを確認し、既存のコンポーネントがこれらのルールに適合しているかを監査してください。
勝手に新しいフォントサイズやフォントファミリーを導入しないでください。

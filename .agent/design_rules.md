# Existence Ticker — デザインルール

このファイルは、本プロジェクトのUIデザイン上の基準・制約を定義するものです。
コード修正やコンポーネント追加を行う際は、常にここを参照してください。

---

## 1. フォントサイズ（スマホ基準）

スマホにおける視認性・ユーザビリティを確保するため、以下の3段階のみを使用します。
**TailwindCSS クラスと実ピクセル値の対応を必ず守ること。**

| 役割                     | TailwindCSSクラス | 実サイズ        | 使用場面                                                                                                |
| ------------------------ | ----------------- | --------------- | ------------------------------------------------------------------------------------------------------- |
| **本文・メインテキスト** | `text-base`       | 16px / 1rem     | 本文、説明文、入力フォーム（`<input>`, `<textarea>`）、ボタンラベル（主要）、wishカード本文             |
| **サブテキスト**         | `text-sm`         | 14px / 0.875rem | カード内の補足説明、リストのサブタイトル、モーダル本文など                                              |
| **極小テキスト**         | `text-xs`         | 12px / 0.75rem  | タイムスタンプ、バッジ内テキスト、注釈（※）、エラーメッセージ補足。**操作自体に影響しない補助情報のみ** |

> ⚠️ **重要**: `<input>` や `<textarea>` のフォントサイズが 16px 未満だと、
> **iOS Safari がタップ時に自動ズームイン**してしまいます。
> フォーム要素には必ず `text-base`（16px）以上を指定すること。

### ❌ 使用禁止のパターン

```tsx
// NG: フォーム入力に text-xs / text-sm を使うと iOS でズームが発生する
<input className="text-xs ..." />
<textarea className="text-sm ..." />

// NG: text-sm をメインの本文テキストに使う（text-base に統一すること）
<p className="text-sm">通常の説明文</p>
```

### ✅ 正しいパターン

```tsx
// OK: フォームには text-base
<input className="text-base ..." />
<textarea className="text-base ..." />

// OK: カード内補足は text-sm
<p className="text-sm text-slate-500">サブ情報</p>

// OK: バッジ・タイムスタンプは text-xs
<span className="text-xs text-slate-400">2時間前</span>
```

## 2. タイポグラフィ全般

### フォントファミリー

| クラス       | 用途                                             |
| ------------ | ------------------------------------------------ |
| `font-serif` | 哲学的・詩的な見出し、世界観を表現する重要な文言 |
| `font-sans`  | 機能的UI、一般的な本文・ラベル・ボタン           |

### 見出しサイズ（ページ・セクション）

| 役割                    | TailwindCSSクラス               | 実サイズ                       |
| ----------------------- | ------------------------------- | ------------------------------ |
| 大見出し / ヒーロー数値 | `text-3xl`（30px）〜 `text-9xl` | ページタイトル、残高表示など   |
| セクション見出し        | `text-xl` 〜 `text-2xl`         | カテゴリ見出し                 |
| コンポーネント見出し    | `text-base`（16px）             | モーダルタイトル、カード見出し |

> `text-6xl` 〜 `text-9xl` は残高などのヒーロー数値のみに許可。

## 3. カラー

- **ベース背景**: `bg-slate-50`
- **ベーステキスト**: `text-slate-900`
- **サブテキスト**: `text-slate-600` / `text-slate-500`
- **アクセント**: 文脈に応じた適切なカラーを使用（汎用的な赤・青・緑を避け、HSLや Tailwind のカラーパレットを活用）

### コントラスト基準（WCAG AA 準拠）

白背景 (`bg-white` / `bg-slate-50`) に対するコントラスト比：

| カラー      | コントラスト比 | 本文 (≥4.5:1) | 補助 (≥3:1) |
| ----------- | -------------- | ------------- | ----------- |
| `slate-900` | 18.1:1         | ✅ 最良       | ✅          |
| `slate-700` | 10.7:1         | ✅ 良好       | ✅          |
| `slate-600` | 7.0:1          | ✅ 良好       | ✅          |
| `slate-500` | 4.6:1          | ✅ 最低限OK   | ✅          |
| `slate-400` | 2.9:1          | ❌ 本文NG     | ✅ 装飾のみ |
| `slate-300` | 1.7:1          | ❌ 禁止       | ❌ 禁止     |

> **ルール**: 読ませる文字（本文・ラベル・説明文）には `text-slate-500` 以上を使うこと。
> `text-slate-400` はアイコン色・ホバー前の初期色・区切り線など「装飾的な用途」のみ許可。

```tsx
// NG: 説明文に slate-400 はコントラスト不足
<p className="text-xs text-slate-400">まだ申し出はありません</p>

// OK: 説明文は slate-500 以上
<p className="text-xs text-slate-500">まだ申し出はありません</p>

// OK: アイコン色・装飾は slate-400 でよい
<Clock className="text-slate-400" />
```

## 4. スペーシング・レイアウト

- コンテンツ最大幅: `max-w-xl` 〜 `max-w-2xl`（スマホ画面に合わせて制約）
- 水平パディング: `px-4`（スマホ）/ `px-6` 〜 `px-8`（タブレット以上）
- タップターゲット: 最小 `44px × 44px`（`py-2.5` + `text-base` で確保）

### アイコンのみのボタン（閉じる・編集・削除など）

アイコンだけのボタンは見た目より実際のタップ領域が重要。

| NG（小さすぎる）  | OK（最小44px確保）    |
| ----------------- | --------------------- |
| `p-1`（約26px）   | `p-3`（約44px）       |
| `p-1.5`（約30px） | `p-2.5`（約38px）以上 |

```tsx
// NG: アイコンだけのボタンに p-1 を使うとタップできない
<button className="p-1"><X size={20} /></button>

// OK: p-3 で最低限のタップ領域を確保
<button className="p-3"><X size={20} /></button>
```

## 5. スマホ描画の最適化（body 設定）

スマホでの視認性はフォント種類より **font-weight と font-smoothing** の影響が大きい。

### `src/index.css` の body 設定

PC とスマホで **font-weight と letter-spacing を分岐** させる。

```css
body {
  /* スマホ (〜767px): Regular で視認性重視 */
  font-weight: 400;
  letter-spacing: 0.05em;
  -webkit-font-smoothing: antialiased;
  -moz-osx-font-smoothing: grayscale;
}

/* PC (768px〜): Light で繊細な世界観を維持 */
@media (min-width: 768px) {
  body {
    font-weight: 300;
    letter-spacing: 0.1em;
  }
}
```

### フォントウェイトの使い分け

| ウェイト      | Tailwind      | 用途                        |
| ------------- | ------------- | --------------------------- |
| 400 (Regular) | `font-normal` | デフォルト本文（body 継承） |
| 500 (Medium)  | `font-medium` | やや強調したい補足文        |
| 700 (Bold)    | `font-bold`   | ボタン・見出し・ラベル      |

> ❌ `font-weight: 200〜300` は **スマホでの使用禁止**。PCでは美しく見えるが、スマホの小画面では判読困難になる。
> フォントスタック（Inter / Noto Sans JP）はスマホ・PCで共通でよい。種類の変更は不要。

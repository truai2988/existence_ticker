# Existence Ticker — デザインルール

このファイルは、本プロジェクトのUIデザイン上の基準・制約を定義するものです。
コード修正やコンポーネント追加を行う際は、常にここを参照してください。

---

## 1. フォントサイズ（スマホ基準）

スマホにおける視認性・ユーザビリティを確保するため、以下の3段階のみを使用します。
**TailwindCSS クラスと実ピクセル値の対応を必ず守ること。**

| 役割                     | TailwindCSSクラス | 実サイズ        | 使用場面                                                                                                |
| ------------------------ | ----------------- | --------------- | ------------------------------------------------------------------------------------------------------- |
| **本文・メインテキスト** | `text-base`       | 16px / 1rem     | 本文、説明文、入力フォーム（`<input>`, `<textarea>`）、ボタンラベル（主要）、wishカード本文             |
| **サブテキスト**         | `text-sm`         | 14px / 0.875rem | カード内の補足説明、リストのサブタイトル、モーダル本文など                                              |
| **極小テキスト**         | `text-xs`         | 12px / 0.75rem  | タイムスタンプ、バッジ内テキスト、注釈（※）、エラーメッセージ補足。**操作自体に影響しない補助情報のみ** |

> ⚠️ **重要**: `<input>` や `<textarea>` のフォントサイズが 16px 未満だと、
> **iOS Safari がタップ時に自動ズームイン**してしまいます。
> フォーム要素には必ず `text-base`（16px）以上を指定すること。

### ❌ 使用禁止のパターン

```tsx
// NG: フォーム入力に text-xs / text-sm を使うと iOS でズームが発生する
<input className="text-xs ..." />
<textarea className="text-sm ..." />

// NG: text-sm をメインの本文テキストに使う（text-base に統一すること）
<p className="text-sm">通常の説明文</p>
```

### ✅ 正しいパターン

```tsx
// OK: フォームには text-base
<input className="text-base ..." />
<textarea className="text-base ..." />

// OK: カード内補足は text-sm
<p className="text-sm text-slate-500">サブ情報</p>

// OK: バッジ・タイムスタンプは text-xs
<span className="text-xs text-slate-400">2時間前</span>
```

## 2. タイポグラフィ全般

### フォントファミリー

| クラス       | 用途                                             |
| ------------ | ------------------------------------------------ |
| `font-serif` | 哲学的・詩的な見出し、世界観を表現する重要な文言 |
| `font-sans`  | 機能的UI、一般的な本文・ラベル・ボタン           |

### 見出しサイズ（ページ・セクション）

| 役割                    | TailwindCSSクラス               | 実サイズ                       |
| ----------------------- | ------------------------------- | ------------------------------ |
| 大見出し / ヒーロー数値 | `text-3xl`（30px）〜 `text-9xl` | ページタイトル、残高表示など   |
| セクション見出し        | `text-xl` 〜 `text-2xl`         | カテゴリ見出し                 |
| コンポーネント見出し    | `text-base`（16px）             | モーダルタイトル、カード見出し |

> `text-6xl` 〜 `text-9xl` は残高などのヒーロー数値のみに許可。

---

## 3. カラー

- **ベース背景**: `bg-slate-50`
- **ベーステキスト**: `text-slate-900`
- **サブテキスト**: `text-slate-500` / `text-slate-400`
- **アクセント**: 文脈に応じた適切なカラーを使用（汎用的な赤・青・緑を避け、HSLや Tailwind のカラーパレットを活用）

---

## 4. スペーシング・レイアウト

- コンテンツ最大幅: `max-w-xl` 〜 `max-w-2xl`（スマホ画面に合わせて制約）
- 水平パディング: `px-4`（スマホ）/ `px-6` 〜 `px-8`（タブレット以上）
- タップターゲット: 最小 `44px × 44px`（`py-2.5` + `text-base` で確保）
